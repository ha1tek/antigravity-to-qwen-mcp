# Правила работы агента Gemini в проекте qwen_mcp

При работе с инструментом `mcp_qwen`:
1. Ты выступаешь строго как **100% Оркестратор**. Самостоятельно код в обход субагента не пишешь.
2. **ЗАПРЕЩЕНО** перефразировать, дополнять или искажать оригинальный запрос пользователя при передаче в `mcp_qwen_submit_task`.
3. **Сбор контекста проекта и лимиты вложений (КАТЕГОРИЧЕСКОЕ ПРАВИЛО)**:
   - **Общий лимит вложений в Qwen Studio — до 10 файлов (до 5 документов + до 5 изображений)**.
   - **ЕСЛИ В ПРОЕКТЕ ЕСТЬ ХОТЬ КАКИЕ-ТО ФАЙЛЫ (код, package.json, компоненты и т.д.)**: Gemini **ОБЯЗАН ВСЕГДА** передавать `project_dir: "<абсолютный путь к проекту>"`. СТРОГО ЗАПРЕЩЕНО оставлять `project_dir` пустым и запрещено описывать проект текстом от себя! Сервер автоматически строит дерево структуры и распределяет файлы:
     * **До 5 документов**: до 4 файлов проекта прикрепляются как документы (`type: ["document"]`) + 1 файл `task_prompt.txt` (содержащий полный промпт, дерево структуры и полный код всех остальных файлов проекта с 5-го по N-й), что полностью обходит лимит поля ввода 131 072 символов. Субагент Qwen 3.8 Max с контекстным окном >1 000 000 токенов прочитывает весь код проекта за один запрос.
     * **До 5 изображений / фотографий / скриншотов**: автоматически сканируются из проекта (папки `references_photos/`, `screenshots/`, `assets/`, `mockups/`) либо передаются явно через параметр `images: ["путь/к/фото.png"]`. Прикрепляются как vision-вложения (`type: ["vision"]`).
   - **Для точечной правки (один файл / локальный фикс)**: НЕ передавай весь проект целиком. Передавай `target_files: ["путь/к/файлу"]` (и при необходимости `images`) — будут прикреплены только целевые файлы для сохранения фокуса.
4. Запускай задачу через `mcp_qwen_submit_task`.
5. Сразу после вызова ставь таймер на 60 секунд через инструмент `schedule` для проверки статуса через `mcp_qwen_check_status`.
6. Не изменяй код субагента при записи на диск (строго 1:1, verbatim).
7. После сборки проекта вызывай `mcp_qwen_verify_task` и дожидайся подтверждения от Qwen субагента ("ПРОЕКТ_СОБРАН_ВЕРНО").
